# 프로젝트 정의서

### (1)프로젝트 명칭
국문: One-Cart (원카트): 흩어진 장바구니 하나로 모으기

영문: Unified Shopping Cart System (USCS)

### (2)명칭 정의
흩어진 장바구니 하나로 모으는 통합 장바구니
### (3)시스템 설명
여러 이커머스 플랫폼(쿠팡, 네이버, 11번가 등)에 흩어져 있는 장바구니 품목을 한곳에서 조회하고 관리할 수 있는 통합 플랫폼입니다. 사용자가 각 사이트를 일일이 방문해야 하는 번거로움을 줄이고, 전체 지출 예정 금액을 한눈에 파악하여 합리적인 소비를 돕는 것을 목적으로 합니다. 모바일 웹 또는 앱 형태로 구현하여 접근성을 높입니다.

### (4)핵심기능
플랫폼별 장바구니 연동: 크롤링 또는 API를 활용해 주요 쇼핑몰의 장바구니 데이터를 실시간으로 동기화.

통합 품목 리스트 및 필터링: 전체 품목을 카테고리별, 가격순, 플랫폼별로 정렬하여 시각화.

최저가 비교 및 알림: 통합된 리스트 내 상품 중 다른 플랫폼에서 더 저렴하게 판매될 경우 가격 비교 정보 제공.

통합 결제 금액 계산기: 배송비를 포함한 전체 예상 결제 금액을 합산하여 예산 관리 기능 제공.

위시리스트 공유 및 보관: 여러 사이트의 상품을 하나의 '공유 바구니'에 담아 친구나 가족에게 전달하는 기능.

### (5)유사 소프트웨어
다나와/에누리: 가격 비교는 강력하지만, '내 장바구니'를 실시간으로 통합 관리하는 기능은 약함.

지그재그 (ZigZag): 여러 쇼핑몰을 모아주지만 의류(패션) 카테고리에 한정되어 있음.

토스(Toss) 쇼핑 탭: 최근 여러 쇼핑몰 결제 내역을 보여주기 시작했으나, 결제 전 단계인 장바구니 관리 단계의 편의성은 아직 미흡함.

분석 결과: 특정 카테고리에 특화된 서비스는 많으나, 생필품부터 가전까지 모든 영역을 아우르는 **'범용적 통합 장바구니'**
