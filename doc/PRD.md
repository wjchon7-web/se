# 요구사항 정의서

## 1. 서 론

### 1.1 문서 목적 및 범위

이 문서는 One-Cart(원카트) 프로젝트의 요구사항을 정의하는 문서이다. 쿠팡, 네이버쇼핑, 11번가 등 여러 이커머스 플랫폼에 흩어진 장바구니 품목을 하나의 통합 플랫폼에서 조회·관리할 수 있도록 시스템을 구축하는 데 필요한 기능적, 비기능적, 인터페이스 요구사항을 정의한다.

### 1.2 프로젝트 개요

#### 1.2.1 프로젝트 정의

One-Cart는 국내 주요 이커머스 플랫폼(쿠팡, 네이버쇼핑, 11번가 등)의 장바구니 데이터를 크롤링 또는 Open API를 통해 실시간으로 수집하고, 사용자에게 통합된 단일 뷰로 제공하는 모바일 웹/앱 서비스이다. 사용자는 각 사이트를 개별 방문하지 않고도 전체 장바구니를 한눈에 확인하고, 합리적인 소비 의사결정을 내릴 수 있다.

#### 1.2.2 주요 기능 설명

| ID | 설명 |
|----|------|
| F01 | 크롤링 또는 OAuth API를 통해 주요 쇼핑몰의 장바구니 데이터 실시간 동기화 |
| F02 | 전체 품목을 카테고리별·가격순·플랫폼별로 정렬하여 통합 리스트 시각화 |
| F03 | 동일 상품이 다른 플랫폼에서 더 저렴하게 판매될 경우 최저가 비교 정보 제공 |
| F04 | 배송비 포함 전체 예상 결제 금액 합산 및 예산 관리 기능 제공 |
| F05 | 여러 사이트 상품을 하나의 공유 바구니에 담아 다른 사용자에게 전달하는 위시리스트 공유 기능 |

### 1.3 유사 소프트웨어 분석

| 서비스명 | 분석 결과 |
|---------|---------|
| 다나와 / 에누리 | 가격 비교 기능은 강력하나, 사용자의 장바구니를 실시간으로 통합 관리하는 기능 부재 |
| 지그재그 (ZigZag) | 여러 쇼핑몰 통합을 제공하나 패션(의류) 카테고리에만 한정됨 |
| 토스(Toss) 쇼핑 탭 | 결제 내역을 보여주지만 결제 전 단계인 장바구니 관리 편의성은 미흡 |
| 분석 결론 | 특정 카테고리 특화 서비스는 있으나, 생필품~가전을 아우르는 범용적 통합 장바구니 서비스는 부재 |

### 1.4 용어 정의

| 용어 | 설명 |
|------|------|
| 장바구니 동기화 | 이커머스 플랫폼의 장바구니 데이터를 크롤링 또는 API를 통해 One-Cart 시스템과 실시간으로 일치시키는 작업 |
| 크롤링 (Crawling) | 웹 페이지를 자동으로 탐색하여 필요한 데이터를 수집하는 기술 |
| OAuth | 사용자 인증 정보를 직접 저장하지 않고, 외부 서비스로부터 접근 권한을 위임받는 인증 프로토콜 |
| API | 응용 프로그램이 운영체제 또는 다른 프로그램의 기능을 사용할 수 있도록 제공하는 인터페이스 |
| 최저가 알림 | 동일 상품이 다른 플랫폼에서 더 저렴하게 판매되는 경우 사용자에게 알려주는 기능 |
| 공유 바구니 | 여러 플랫폼의 상품을 모아 타인과 공유할 수 있는 위시리스트 |

## 2. 요구사항

### 2.1 기능적 요구사항

#### 2.1.1 회원 및 인증 기능

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| FR-001 | 사용자는 이메일, 비밀번호를 입력하여 회원가입을 할 수 있다. | 상 |
| FR-002 | 사용자는 소셜 계정(Google, Kakao)으로 간편 로그인할 수 있다. | 상 |
| FR-003 | 사용자는 이메일, 비밀번호를 입력하여 로그인한다. | 상 |
| FR-004 | 사용자는 자신이 연동한 쇼핑몰 계정 목록을 마이페이지에서 확인할 수 있다. | 상 |
| FR-005 | 사용자는 비밀번호를 분실 시 등록된 이메일을 통해 재설정할 수 있다. | 중 |

#### 2.1.2 쇼핑몰 연동 기능

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| FR-006 | 사용자는 연동할 쇼핑몰(쿠팡, 네이버쇼핑, 11번가 등)을 선택하고 OAuth 인증 또는 계정 정보를 입력하여 연동할 수 있다. | 상 |
| FR-007 | 시스템은 연동된 쇼핑몰의 장바구니 데이터를 주기적으로 동기화한다. | 상 |
| FR-008 | 사용자는 연동된 쇼핑몰을 언제든지 해제할 수 있다. | 중 |
| FR-009 | 시스템은 쇼핑몰 연동 실패 시 사용자에게 실패 사유와 함께 알림을 제공한다. | 상 |

#### 2.1.3 통합 장바구니 조회 기능

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| FR-010 | 사용자는 연동된 모든 쇼핑몰의 장바구니 품목을 하나의 통합 리스트로 조회할 수 있다. | 상 |
| FR-011 | 사용자는 통합 리스트를 플랫폼별, 카테고리별, 가격순으로 필터링 및 정렬할 수 있다. | 상 |
| FR-012 | 사용자는 각 품목의 상품명, 가격, 수량, 배송비, 판매 플랫폼 정보를 확인할 수 있다. | 상 |
| FR-013 | 시스템은 통합 장바구니의 전체 예상 결제 금액(배송비 포함)을 합산하여 표시한다. | 상 |
| FR-014 | 사용자는 품목별 수량을 One-Cart 내에서 수정할 수 있다. | 중 |
| FR-015 | 사용자는 원하지 않는 품목을 One-Cart 내에서 삭제할 수 있다. | 중 |

#### 2.1.4 최저가 비교 및 알림 기능

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| FR-016 | 시스템은 장바구니 내 상품이 다른 연동 플랫폼에서 더 저렴하게 판매되는 경우 가격 비교 정보를 제공한다. | 상 |
| FR-017 | 사용자는 특정 상품의 가격이 설정한 목표 가격 이하로 내려가면 앱 푸시 알림 또는 이메일로 통보받는다. | 중 |
| FR-018 | 시스템은 최저가 정보를 클릭 시 해당 플랫폼의 상품 상세 페이지로 이동시킨다. | 상 |

#### 2.1.5 예산 관리 기능

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| FR-019 | 사용자는 월별 쇼핑 예산을 설정할 수 있다. | 중 |
| FR-020 | 시스템은 통합 장바구니의 총 금액이 설정된 예산에 근접하거나 초과하는 경우 경고를 표시한다. | 중 |
| FR-021 | 사용자는 예산 대비 현재 장바구니 총액의 비율을 시각적으로 확인할 수 있다. | 하 |

#### 2.1.6 위시리스트 공유 기능

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| FR-022 | 사용자는 여러 플랫폼의 상품을 담은 공유 바구니를 생성할 수 있다. | 중 |
| FR-023 | 사용자는 생성된 공유 바구니의 링크를 생성하여 타인에게 공유할 수 있다. | 중 |
| FR-024 | 공유 링크를 받은 사용자는 로그인 없이 공유 바구니를 열람할 수 있다. | 중 |
| FR-025 | 공유 바구니를 받은 사용자는 해당 상품을 자신의 장바구니에 추가할 수 있다. | 하 |

### 2.2 비기능적 요구사항

#### 2.2.1 운영 환경에 대한 요구사항

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| NFR-001 | 시스템은 Android 8.0 이상 및 iOS 13.0 이상 모바일 환경을 지원한다. | 상 |
| NFR-002 | 시스템은 Chrome, Safari, Edge 최신 버전의 모바일 웹 브라우저에서 동작한다. | 상 |
| NFR-003 | 서버 시스템은 클라우드 환경(AWS 또는 GCP)에서 운영된다. | 상 |

#### 2.2.2 성능 요구사항

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| NFR-004 | 시스템은 모든 사용자 요청에 대해 3초 이내로 응답한다. | 상 |
| NFR-005 | 시스템은 연동된 쇼핑몰의 장바구니 데이터를 5분 이내 주기로 동기화한다. | 상 |
| NFR-006 | 시스템은 동시 접속 사용자 1,000명 이상을 안정적으로 처리할 수 있어야 한다. | 중 |
| NFR-007 | 데이터베이스는 사용자의 장바구니 변경 사항을 실시간으로 반영한다. | 상 |

#### 2.2.3 보안 요구사항

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| NFR-008 | 시스템은 모든 사용자 개인정보 및 쇼핑몰 연동 정보를 AES-256 이상의 알고리즘으로 암호화하여 저장한다. | 상 |
| NFR-009 | 시스템은 외부 쇼핑몰 인증 시 OAuth 2.0 프로토콜을 준수하여 사용자 비밀번호를 직접 저장하지 않는다. | 상 |
| NFR-010 | 시스템은 HTTPS를 통해서만 데이터를 전송한다. | 상 |
| NFR-011 | 시스템은 개인정보보호법 및 정보통신망법에 따른 개인정보 처리방침을 준수한다. | 상 |

| 분류 | 요구사항 | 우선순위 |
|------|---------|--------|
| NFR-012 | 시스템은 한국어 및 영어 인터페이스를 지원한다. | 중 |
| NFR-013 | 모바일 UI는 반응형으로 설계되어 다양한 화면 크기에서 적절히 표시된다. | 상 |
| NFR-014 | 사용자는 최초 연동 시 5단계 이내의 절차로 쇼핑몰 계정 연동을 완료할 수 있다. | 중 |
