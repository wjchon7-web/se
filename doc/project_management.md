# [프로젝트 계획서] One-Cart (원카트): 통합 장바구니 시스템

---

## 1. 개요 (Introduction)
### 1.1 문서의 목적
본 문서는 'One-Cart' 프로젝트의 개발 전반에 대한 계획을 수립하고, 팀원 간의 협업 방식 및 개발 공정을 정의하여 프로젝트를 성공적으로 완수하는 것을 목적으로 합니다.

### 1.2 프로젝트 개요
* **명칭:** One-Cart (원카트) / Unified Shopping Cart System (USCS)
* **설명:** 쿠팡, 네이버, 11번가 등 여러 이커머스 플랫폼에 흩어져 있는 장바구니 품목을 한곳에서 조회하고 관리하는 통합 플랫폼입니다.
* **핵심 기능:** 플랫폼별 데이터 실시간 동기화, 최저가 비교 및 알림, 통합 결제 금액 계산기 등.

### 1.3 관련 문서, 용어 및 약어
* **관련 문서:** 프로젝트 정의서 v1.0
* **주요 용어:**
    * **USCS:** Unified Shopping Cart System의 약자.
    * **Crawling:** 외부 웹사이트에서 데이터를 자동으로 수집하는 기술.

## 2. 개발 계획 (Development Plan)
### 2.1 프로세스 모델 및 개발 방법론
* **Agile (Scrum):** 기능 단위의 빠른 개발과 피드백 수용을 위해 애자일 방법론을 채택합니다.

### 2.2 작업 분할도 (Work Breakdown Structure)
1. 환경 설정 및 오픈 API 분석
2. 쇼핑몰 데이터 크롤링 모듈 개발
3. Firebase 데이터베이스 연동 및 동기화 구현
4. UI/UX 디자인 및 프론트엔드 개발
5. 통합 테스트 및 버그 수정

### 2.3 소요 자원 (Staffing, Cost)
* **인력:** 천원재
* **예산:** 오픈소스 라이브러리 및 클라우드 무료 티어(Firebase 등) 활용으로 비용 최소화.

### 2.4 일정 계획 (Gantt Chart)
* **1~2주차:** 요구사항 정의 및 시스템 설계
* **3~6주차:** 주요 기능 구현 (Kotlin/Python)
* **7주차:** 품질 검수 및 최종 배포

## 4. 기술 관리 계획 (Technical Management)
### 4.1 버전 관리
* **소프트웨어:** 파일명 맨 앞에 버전을 기재하며, GitHub를 통해 소스 코드를 관리합니다.
* **문서:** 파일명 맨 뒤에 날짜를 기재하고, 클라우드 및 GitHub에 병행 저장하여 제/개정 이력을 관리합니다.

### 4.2 형상 관리
* **Naming 규칙:** `[팀명]문서명_YYMMDD_Doc-v버전` 형식을 적용하여 산출물을 식별합니다.

### 4.3 기술 관리
* 기능 변경 시 팀원 전체의 권한 및 다수결 합의를 거치며, 변경 전/후 내용을 기록물로 보존합니다.
