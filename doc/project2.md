# 대상 시스템 품질 요소 추정하기
### (1) 사용자가 원하는 기대치
**사용성 (Usability):** 여러 쇼핑몰의 정보를 한눈에 파악할 수 있는 직관적인 UI/UX와 간편한 연동 과정.

**신뢰성 (Reliability):** 각 쇼핑몰의 실제 장바구니 상태와 앱 내 데이터가 실시간으로 정확하게 일치해야 함.

**보안성 (Security):** 쇼핑몰 계정 정보나 개인의 구매 의사가 담긴 장바구니 데이터가 외부로 유출되지 않아야 함.

### (2) 개발자 혹은 유지보수 담당자가 원하는 기대치
**유지보수성 (Maintainability):** 쇼핑몰(쿠팡, 네이버 등)의 웹 구조가 변경되었을 때, 크롤링 엔진이나 API 연동 로직을 빠르게 수정할 수 있는 구조.

**이식성 (Portability):** 안드로이드, iOS 등 다양한 모바일 환경이나 웹 브라우저에서 동일하게 동작할 수 있는 설계.

**테스트 용이성 (Testability):** 복잡한 로그인 세션 유지나 데이터 파싱 로직이 제대로 작동하는지 개별적으로 검증 가능한 코드 구조.

### (3) 개발 조직의 관리자가 원하는 기대치
**생산성 (Productivity):** 오픈 소스 라이브러리(Selenium, BeautifulSoup 등)를 적극 활용하여 정해진 학기 내에 핵심 기능을 구현 완료하는 것.

**상호 운용성 (Interoperability):** 향후 더 많은 쇼핑몰 플랫폼이나 결제 시스템과 추가로 연동될 수 있는 확장 가능성.

**안정성 및 리스크 관리:** 크롤링 차단 등 외부 요인으로 인해 서비스가 중단될 리스크를 최소화하고 대안을 마련하는 능력.
